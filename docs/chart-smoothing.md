# Плавные графики активности Signal

Общий переключатель «Плавно / По снимкам» в заголовке анализа активности управляет обоими SVG-графиками. По умолчанию выбран плавный режим. Переключение не меняет API-запросы, выбранные окна, период, фильтры или таблицу. Старый Plotly-компонент не изменяется.

Сглаживание применяется только при отображении: монотонная кубическая интерполяция Hermite (PCHIP), без усреднения исходных данных. Производные каждой серии дополнительно уменьшаются общим коэффициентом, ограниченным производной суммы. Серии и общая активность остаются в пределах соседних измерений, накопительные области не пересекаются. Промежуточные значения не участвуют в расчётах таблицы.

SVG использует общую плотную сетку с дробными секундами: 4–12 подразделений на интервал в зависимости от количества точек, координаты с точностью до 0,001 пикселя. Все линии и заливки строятся по одной сетке, включая верхнюю область до линии «Всего». Расчёт мемоизирован при неизменных данных и размерах графика.

Пропуски более 1,5 шага сбора разделяют график на независимые области, как в существующем ступенчатом режиме. Изолированный снимок отображается горизонтальным отрезком в пределах своего bucket. Режим «По снимкам» сохраняет прежние ступени и длительность последнего bucket в пределах диапазона.

Подсказки используют существующий поиск ближайшего исходного снимка. Темы, фильтрация легендой, перемещение и изменение ширины окон сохраняются.

Проверки входят в штатный Vitest: прохождение через исходные точки, неизменность API-данных, отсутствие выбросов у серий и суммы, непрерывность касательных, пропуски, пустые/одиночные данные, границы заливок и общий переключатель без дополнительных запросов.

API предполагает упорядоченные снимки и согласованные totals/series из существующего контракта.
