# Signal: темы приложения

Реализованы согласованные светлая и тёмная темы Signal. Тёмная используется по умолчанию. Общие семантические токены (`src/signal.css`) применяются к дашборду, странице объектов, формам, SQL-диалогу, меню и графикам. Tailwind остаётся существующим слоем компоновки.

Переключатель находится в футере бокового меню, сохраняет выбор в `localStorage` (`dbperf-theme`), синхронизируется между вкладками одного origin и продолжает работать при недоступном хранилище. При переключении не меняются период, выделенные интервалы, фильтры и вкладка таблицы. В свёрнутом меню доступны иконки, на мобильных экранах переключатель остаётся под навигацией.

Оба графика используют накопительные цветные области, второй также показывает границы слоёв и линию суммы. Цвета серий согласованы с легендой, таблицей и профилем. Ступени соответствуют отдельным снимкам, пропуски данных не закрашиваются. KPI перенесены над графиками.

## Проверки

- `npm run build`: TypeScript и production build прошли.
- `npm test`: 22 теста прошли, включая выбор/сохранение темы, keyboard, storage failure/sync и области с пропусками.
- Через браузер проверены обе темы на реальных данных, сохранение темы после обновления, сохранение фильтра легенды, SQL-диалог, выбор периода, страница объектов и форма создания (без сохранения).
- Проверены 1366×768, 1024×768, 390×844, 320×740: без горизонтального переполнения страницы; на настольных размерах проверенная таблица помещается по высоте.
- `npm run test:coverage`: тесты проходят, общий gate НЕ пройден: lines 20.43%, branches 12.29% при пороге 90%. Порог и список исключений не изменялись. Полный регрессионный E2E harness в этом проходе не запускался; выполнены перечисленные проверки в браузере.

Локальная production-сборка обновлена через `docker compose -f deploy/docker-compose.yaml up -d --no-deps --build ui`: http://localhost:8081/#/t/2/activity. Dev-сервер также доступен на http://localhost:5173.
