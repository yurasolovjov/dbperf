# Frontend coverage

Область: `services/dbperf-ui`, Vitest 4.1.11, coverage provider V8. Измеряется весь `src/**/*.{ts,tsx}`, включая неимпортированные файлы. Исключения не расширялись: только `src/**/*.test.{ts,tsx}`, `src/test/**` (fixtures/setup), `src/**/*.d.ts`. CSS и декларации типов не являются исполняемым TypeScript.

## Запуск

```sh
cd services/dbperf-ui
npm ci --no-audit --no-fund
npm run test:coverage
npm run build
```

В корне доступна команда `make test-ui` (coverage и typecheck); общий `make test` также включает этот gate.

Глобальный gate: минимум 90% строк и 90% ветвей, команда завершается с ошибкой при недостижении любого порога. Отчёты: `coverage/index.html`, `coverage/coverage-summary.json`. Четыре worker-процесса ограничивают одновременные окружения jsdom; timeout интеграционного теста — 15 с, ожидание состояния через Testing Library — до 5 с.

На 26.10.2026: **88 тестов, 17 файлов; строки 99.80% (1003/1005), ветви 97.65% (1001/1025)**. Statements: 99.57%, functions: 99.74%. `npm run build` включает проверку TypeScript.

## Что проверяется

- Реальные компоненты и hooks: маршруты App, sidebar, страница объектов, CRUD, подтверждение удаления, конфликты revision, поиск и редактирование меток.
- YAML: обе структуры документа, единицы длительности, значения по умолчанию, валидация, предпросмотр, исключение невалидных строк, частичные результаты, ошибки файла и транспорта.
- Дашборд: API-параметры, периоды, обе выборки графика, легенда, общие и табличные фильтры, смена вкладок/единиц, пагинация, профиль и его уровни, SQL-диалог, native/fallback fullscreen и Escape.
- Графики: накопительные области, ступени и пропуски, пустые данные, pointer/keyboard операции, семантические цвета, обработчики существующих Plotly-компонентов.
- SQL: отмена устаревшего ответа, retry, clipboard API и fallback, ошибки копирования, закрытие и добавление hash в фильтр.
- Темы: keyboard, сохранение выбора, синхронизация вкладок, отказ localStorage. API: пагинация реестра, FieldMask/revision, int64, string hashes и ошибки HTTP.

API и внешний Plotly renderer подменяются на границе, чтобы тесты не зависели от локального Docker/сети/WebGL. Компоненты, расчёты и состояние React выполняются реально. jsdom восполняет только отсутствующие browser primitives (dialog, ResizeObserver, pointer capture); это не замена визуальным и браузерным E2E-проверкам. Backend и E2E coverage в проценты выше не входят. 24 непокрытые ветви остаются в основном в запасных/защитных путях; 100% не заявляется.

## Найденные ошибки

- Clipboard fallback удаляет временное поле через `finally`, включая исключения `execCommand`.
- Декоративная галочка выбранной опции скрыта от accessibility tree и не меняет доступное имя опции.

## CI

`.github/workflows/frontend-tests.yml` запускает `npm ci`, coverage gate и production build для push/PR с изменениями UI; HTML/JSON coverage сохраняются артефактом. Workflow подготовлен локально; запуск на GitHub проверяется после публикации изменений.
