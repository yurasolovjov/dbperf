# dbperf-ui

Фронтенд dbperf: дашборд «Активность сессии» и управление объектами мониторинга. React 18, TypeScript, Vite, Plotly, js-yaml. Страницу
отдаёт Nginx, который проксирует `/api/` в JSON-шлюз dbperf (`:9091`).

```bash
npm install
npm run dev        # http://localhost:5173, /api проксируется в localhost:9091 (DBPERF_API переопределяет)
npm run build      # dist/
```

На стенде: `make up` в корне репозитория собирает бандл и поднимает `ui` на http://localhost:8081.

Что умеет страница:

- период (1 мин … 1 день, произвольный), разрез, автообновление;
- обзорный график за период со скользящим окном: выделите область мышью;
- окно в двух видах: **Профиль** — flame graph на Plotly `icicle` (ширина узла = доля снимков окна,
  уровни = разрезы в выбранном порядке, клик приближает узел, Ctrl/⌘-клик добавляет фильтр,
  Shift-клик по запросу показывает текст, кнопка «перевернуть» меняет корень и листья местами)
  и **График** — временной ряд за окно, клик по легенде добавляет фильтр, чекбокс «Общая активность»;
- таблица топа по вкладкам-разрезам, полоса раскрашена по типам ожиданий, переключатель СКАС / %,
  раскрытие строки до типов ожиданий, клик по полосе добавляет фильтр, клик по SQL показывает текст.

Маршруты: `#/targets` — объекты мониторинга (таблица, создание, изменение, включение,
удаление, импорт YAML в формате `deploy/dbperf/targets.yaml` через `BulkCreateTargets`
порциями по 1 000); `#/t/<id>/activity?dim=QUERY` — дашборд инстанса. Боковая панель
перечисляет все объекты с владельцем-коллектором и открывает дашборд каждого. Запросы к
реестру идут через `/api/v1/registry/`, который Nginx проксирует в dbperf-registry (`:9101`).

Старый адрес `#target=2&dim=QUERY` по-прежнему открывает дашборд.
